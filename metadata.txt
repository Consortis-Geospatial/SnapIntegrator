about=SnapIntegrator is a QGIS plugin for detecting potential topology and attribute inconsistencies in road networks. It analyzes shared endpoints between line features, supports comparison of one or multiple attribute fields, and can optionally filter results using a selected polygon boundary. The plugin can identify connected road segments with different or identical attribute values and exports the detected locations to a temporary point layer.
